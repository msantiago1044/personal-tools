# Regla de Automatización: Git Commit y Push Automático

- **Regla Mandatoria del Usuario:** Siempre realizar `git add`, `git commit` y `git push` automáticamente una vez que una tarea, cambio o módulo nuevo haya sido implementado y validado.
- **Razón:** El usuario estableció explícitamente no tener que dar la instrucción de `push` en cada sesión ni ser consultado antes de enviarlo a `origin/main`.
- **Formato de commit:** Usar Conventional Commits (`feat: ...`, `fix: ...`) con descripción concisa y profesional en español.
